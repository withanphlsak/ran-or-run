โปรเจคนี้ผมสร้างขึ้นมาเพื่อเเสดงข้อมูลรูปเเบบการวิ่งตามที่เราตั้งไว้ในเเต่ละวันมาเเสดงในวันปัจจุบัน ผมทำขึ้นมาเพราะเวลาผมต้องไปวิ่งเเล้วบางครั้งมีการจัดตารางไว้เเล้วเอาไปไว้ในโน๊ตเเต่ผมรู้สึกว่าตัวข้อมูลมันดูยากเพราะมันมันเป็นข้อความที่ต่อกันมาเเล้วก็เว็บนี้ผมไม่ต้องคอยไปหาว่าอันไหนคือโปรเเกรมวิ่งวันนี้เเต่เว็บเปิดมาก็คือสิ่งที่เราต้องวิ่งวันนี้เลย สิ่งที่ผมได้รับคือ ผมได้ฝึกสกิลการใช้ ส่วนของfrontend คือ html,css,javascript เเละ backend/database  คือ Postgresql มากขึ้น (เเล้วในอนาคตผมก็มีเเผนที่จะพัฒนาเพิ่มระบบต่างๆให้มากขึ้น)
